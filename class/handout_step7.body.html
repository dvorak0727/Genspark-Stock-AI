為什麼要看五個週期，不是只看一個？

階段是一段時間的故事，不是一天的照片。同一檔股票，看 5 天可能像「啟動」，看 30 天可能還只是「看不出」，兩個都沒錯，只是看的時間尺度不同。

  • 短週期（5、10 天）：反應快，能抓到最近的變化，但容易被一兩天的大量騙到。
  • 長週期（20、30、60 天）：比較穩，但慢半拍。
  • 兩者一致：結論比較可靠。兩者不一致：代表短線和長線在講不同的故事，要小心，這本身就是有用的訊息。

為什麼是 5、10 這麼短？這是老師近來看盤的觀察：法人的操作週期好像變短了，投信大約 5 天、外資大約 10 天。這個說法老師還沒有用資料驗證，請當成「選窗口的理由」，不要當成定論。

寫在最前面

「看不出明確的階段」是最常見的結果，也是最誠實的結果。階段名稱只是把數字整理成一句話，不是預測，更不是叫你買或賣。

請 AI 把階段卡片換成多週期表

指令 14　多週期階段卡片
下面是我的「迷你台股分析器」網頁程式碼。請把「現在像哪一個階段？」那張卡片，換成「五個週期一起看」的版本，其他卡片不要動。

做法與規則：
1. 週期共五個：5、10、20、30、60 日。每個週期各自算出一個階段，全部用資料裡完整的 const DATA（不要受「顯示天數」按鈕影響）。
2. 每個週期 N 要算這些數字（目前選到的股票）：
   ・位階＝（最新收盤 － 近 N 個交易日最低價 l）÷（近 N 個交易日最高價 h － 近 N 個交易日最低價 l）× 100%，近 N 日包含最新這一天。
   ・量比＝最新一天成交量 v ÷「前 N 個交易日」的平均成交量（不含最新這一天）。
   ・外資＋投信累計＝最近 N 天的外資 f 加投信 t 的買賣超加總。
   ・融資變化＝最新一天的 m 減去 N 個交易日前的 m。
   ・股價變化＝最新收盤價減去 N 個交易日前的收盤價。
   ・今天是不是紅 K＝收盤價 c 大於開盤價 o。
3. 門檻請放在程式最上面的一個設定物件：高位階 70、低位階 40、爆量 1.5、窒息量 0.7。
4. 判斷順序，符合第一個就停：
   ・出貨：位階 ≥ 70 且 量比 ≥ 1.5 且 外資＋投信累計 < 0
   ・啟動：量比 ≥ 1.5 且 今天紅 K 且 外資＋投信累計 > 0 且 位階 < 70
   ・拉升：位階 ≥ 70 且 外資＋投信累計 > 0 且 股價變化 > 0 且 量比 ≥ 1
   ・洗盤：位階 ≤ 40 且 融資變化 < 0 且 股價變化 < 0
   ・吸籌：位階 ≤ 40 且 量比 ≤ 0.7
   ・都不符合：看不出
5. 資料不夠的週期：算一個週期需要「N＋1 個交易日」的資料。不夠就整列顯示「資料不足：需要至少 N+1 個交易日，目前只有 X 個」，不要硬算、不要用別的數字代替。分母是 0（價格完全沒變、前 N 日沒有成交量）也要寫「算不出來」，不可以出現 NaN 或 undefined。
6. 卡片用一張表：每列一個週期，欄位為「週期、判斷、位階、量比、外資＋投信累計、融資變化、股價變化」，判斷用表情符號加名稱（⚠️ 出貨、🔥 啟動、📈 拉升、🌀 洗盤、😴 吸籌、看不出）。
7. 表的上面用大字寫一句總結：如果所有算得出來的週期結論都一樣，寫「各週期的結論一致：XX（5、10 日）」；不一樣就寫「各週期的結論不一致：「XX」：5 日；「看不出」：10、20 日」。
8. 表的下面放一個可展開的說明，列出上面五條規則和目前的門檻數字；再放一行小字：「這是把數字整理成階段名稱的簡化判讀，不是預測，也不是買賣建議。」
9. 不要出現「適合買進」「適合快進快出」之類的建議用語。

請輸出完整的 HTML 檔案，不要省略任何部分。其他部分不要改動，原本的資料區（const DATA）請原樣保留。

按下去之後，這段指令後面會自動接上存檔點 6 的完整程式碼。

  1. 切到 AI 聊天的新對話，點輸入框，按 Ctrl + V 貼上（Mac 按 ⌘ + V），按送出。
  2. 等 AI 寫完，在預覽裡看階段卡片。這一步不需要網路，預覽就能測。

驗收

你的 AI 跟範例不一樣時

先檢查：每一列的天數對不對（5 日就是用 5 天，不是 15 天或 60 天）、60 日有沒有硬算出數字（不該有）、有沒有加建議用語。如果不對，用下面的指令請它改。

指令　AI 偷改了天數或亂算時用
多週期階段表和我給的規則不一樣。請檢查：1.每一列的位階、量比、累計、變化，都要用該列自己的天數 N（5、10、20、30、60），不能共用同一個天數。2.資料不到 N＋1 個交易日的週期，要整列寫「資料不足」，不能硬算數字。3.不要出現任何買賣建議的用語。改好後輸出完整的 HTML 檔案，其他部分不要動，資料區（const DATA）原樣保留。
AI 回答「找不到」時（有些免費 AI 會忘記上一份程式碼）

這不是你做錯，是它沒記住，而且它沒有亂編，反而是好事。照下面做：

  1. 找到 AI 上一次給你的完整程式碼區塊，按它右上角的「複製」圖示。
  2. 點聊天輸入框，先貼上這份程式碼（Ctrl + V），換一行，再貼上本頁的指令，一起送出。

貼上後 AI 只收到前面一小段（例如 Gemini 免費版，貼太長會被截斷）：改用「上傳檔案」。按 AI 程式碼區塊的下載圖示，把程式碼存成網頁檔；在 AI 聊天按「＋」上傳那個檔案；再貼上指令，並在最前面補一句「在上傳的檔案，再新增以下功能」。這樣就不會被截斷。

一次只送一個指令。不要把「指令＋存檔點」按鈕複製的內容，和別的指令塞在同一則訊息裡：AI 常常只做第一個，後面的就當沒看到。要貼的程式碼，是 AI 上一次回給你的那份，不是按紅色大按鈕複製的那份。

讀「一致」與「不一致」

把六檔股票各點一遍，把表上方那句話念出來。

你看到的可以怎麼想
各週期都「看不出」最常見。沒有哪個週期出現明顯的組合，先觀察。
短週期有階段、長週期看不出最近才出現的變化，還沒有累積成長期的故事。要看接下來幾天會不會延續。
多個週期同一個階段短線和長線說同一件事，比只有一個週期有說服力。但仍然只是整理數字，不是預測。
各週期結論相反短線和長線在打架，小心解讀。
看答案

會可疑。真實的市場大部分時間沒有明確的階段，一個永遠有答案的工具，多半是在硬猜。我們的頁面寧可寫「看不出」或「資料不足」，這是它可信的地方。

結業

今天學到的

  • 同一套規則，換不同的天數，會得到不同的結論。
  • 看各週期「一致不一致」，比看單一週期更有資訊。
  • 資料不夠 N＋1 天，就老實說「資料不足」，不硬算。
  • 門檻是人訂的，結果是整理數字的簡化判讀，不是預測。
