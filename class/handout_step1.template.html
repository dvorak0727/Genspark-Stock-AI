指令 1　三大法人卡片
下面是我的「迷你台股分析器」網頁程式碼。請在股價圖的下面，新增一張「三大法人買賣超」卡片。

規則：
1. 資料用 f（外資）、t（投信）、s（自營商自行買賣），單位都是「張」。
2. 用表格列出外資、投信、自營商三列，欄位是：最新一天買賣超、近 5 日累計、連續買超或賣超的天數。連續天數的算法：從最新一天往回數，同方向連續幾天，遇到 0 就中斷。
3. 表格下面畫近 5 日長條圖，每天三根（外資、投信、自營商）。買超向上用紅色，賣超向下用綠色（台股習慣：紅漲綠跌）。
4. 圖下面用一句白話判讀：外資和投信同時連買 3 天以上，寫「法人方向一致偏多」；同時連賣 3 天以上，寫「法人方向一致偏空，要小心」；兩邊方向不同，寫「訊號分歧，先觀察」；其他情況寫「沒有明顯的連續訊號」。
5. 卡片最後加一行提醒：自營商只算「自行買賣」，避險不算；並請使用者到 HiStock 核對最新一天的外資買賣超。

請輸出完整的 HTML 檔案，不要省略任何部分。資料區（const DATA）請原樣保留，不要修改。

按下去之後，這段指令後面會自動接上起點頁的完整程式碼。

核對：數字是真的嗎？

AI 寫的程式會出錯，而且錯得很安靜。畫面一樣漂亮，數字卻全是錯的。所以我們養成一個習慣：做完一個功能，就拿外面的網站對一次答案。

  1. 打開 HiStock 台積電的籌碼頁，找標題寫「近三十日三大法人買賣超」的表格。
  2. 找到 2026/10/02 那一列。表格的欄位是：日期、外資、投信、自營(自買)、自營(避險)、總計。
  3. 回到你自己的頁面，對照表格裡的「最新一天」：外資應該是 −5,914，投信 254，自營商（自行買賣）146。

1-415 分鐘

用白話看懂這張卡片

名詞白話
三大法人外資、投信、自營商。三種「大戶」的合稱。
外資外國的大型投資機構。錢最多，通常決定大方向。
投信國內的基金公司，也就是幫大家管基金的人。
自營商券商拿自己的錢買賣股票。我們只看「自行買賣」那一部分，「避險」不算，因為避險只是在對沖，不代表看多或看空。
買賣超今天買進的比賣出的多多少。多就是「買超」，少就是「賣超」。
張台股的單位，1 張 ＝ 1000 股。
連買／連賣從最新一天往回數，連續幾天都是買超（或都是賣超）。

為什麼看「連續」，不看單日？單日買賣超可能只是偶然。連續好幾天朝同一個方向，比較像是有計畫的動作。

練習：看台積電 10/02 的畫面，回答三個問題

看答案

外資賣超 5,914 張（綠色）。投信連買 4 天。兩邊方向不同，所以頁面說「訊號分歧，先觀察」。自營商（自行買賣）連買 3 天。

這代表：外資今天出了一大批，但投信連續 4 天在買。誰對誰錯現在還不知道，所以不要急著下結論。

加料（二選一）

接在剛剛同一個 AI 對話裡，直接貼就好，不用再貼程式碼。

加料 A　字放大，看得更清楚
請直接修改「你剛剛輸出的那份完整 HTML」，不要另外重新做一個新的頁面，資料只能用那份 HTML 裡的 const DATA，不可以自己編數字。如果你找不到剛剛那份 HTML，請直接回答「找不到」。

請把剛剛那個網頁的字體整體放大約 20%，表格和按鈕也一起放大，讓年長的人也看得清楚。請輸出完整的 HTML 檔案，資料區（const DATA）請原樣保留。
加料 B　K 線圖加一條 20 日均線
請直接修改「你剛剛輸出的那份完整 HTML」，不要另外重新做一個新的頁面，資料只能用那份 HTML 裡的 const DATA，不可以自己編數字。如果你找不到剛剛那份 HTML，請直接回答「找不到」。

請在剛剛那個網頁的 K 線圖上，加一條 20 日均線（最近 20 天收盤價的平均），用橘色細線畫，並在圖的下方加一行說明「橘線＝20 日均線，股價在線上方代表近期偏強」。前面不足 20 天的地方不要畫。請輸出完整的 HTML 檔案，資料區（const DATA）請原樣保留。

做完之後別忘了回到 1-3 的習慣：看看新加的東西對不對。均線的話，可以拿 Yahoo 股市的 20 日均線對一下。

也要確認：股票按鈕、K 線、三大法人卡片都還在。如果頁面突然變得很簡陋、數字特別整齊（例如成交量剛好是 12,500），多半是 AI 自己重新做了一個新頁面，數字是編的。這時請改用「存檔點 1」。
